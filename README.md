**DEPRECATED: IBM CICS TS Operator collection**
========================

The **IBM® CICS® TS Operator collection** is no longer supported. Use the **IBM z/OS CICS collection**, part of the **Red Hat® Ansible Certified Content for IBM Z** instead. For information, see the [ibm_zos_cics](https://github.com/ansible-collections/ibm_zos_cics) repo.
